GED Practice Platform

The GED Practice Platform is a full-stack web application designed to simulate real GED testing conditions and improve student performance through structured, data-driven practice.

Key Features
Dynamic Test Generation – Builds full-length GED-style tests from a large, categorized question bank
Realistic Testing Interface – Clean UI with navigation, flagging, and distraction-free layout
Answer Review System – Provides correct answers and strategy-based explanations after submission
User Accounts & Progress Tracking – Saves test progress and performance to user accounts
Customizable UI Settings – Includes light mode, dark mode, and original theme options
Improved Usability Features – Flagging system, intuitive controls, and optimized layout for focus

This platform is built to help users practice efficiently, identify weaknesses, and improve test-taking strategies over time.
